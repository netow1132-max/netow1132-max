## 🚀 Projetos em destaque

### 📦 Central de Automação Logística — PATY MAIONESE

Aplicativo desktop em Python que reúne soluções para rotinas documentais da logística.

- Relacionamento entre **CT-e, faturas e notas fiscais em PDF**
- Organização e junção automática de documentos
- Conversão e mapeamento de informações de **PDF para Excel**
- Dashboard de volumetria e acompanhamento operacional
- Interface gráfica construída com **PySide6**

`Python` `PySide6` `PDF` `Excel` `Automação`

---

### 💰 Painel de Finanças Pessoais

Aplicação criada para tornar o planejamento financeiro mais visual e simples.

- Controle de renda, contas e orçamento por categoria
- Cálculo automático do saldo disponível
- Metas financeiras e projeção de aportes
- Gráficos de planejamento e acompanhamento
- Área de investimentos e organização mensal

`Python` `Dashboards` `Finanças` `Visualização de dados`

---

### 📊 Automação de Planilhas e Documentos

Conjunto de soluções criadas para eliminar tarefas repetitivas.

- Renomeação de PDFs usando dados de planilhas
- Cruzamento e tratamento de informações no Excel
- Ajustes automáticos em arquivos XML
- Extração de dados de documentos logísticos
- Relatórios e dashboards para tomada de decisão

`Excel` `Python` `XML` `Power BI` `Processamento de dados`
